## 4. Зафиксированные направления продукта

В проектной документации согласованы основные направления:

- организации и управление участниками;
- авторизация по телефону через SMS OTP;
- коммерческая модель и entitlements;

- дополнительные модули;
- медиагалерея.

## 7. Ограничения и важные замечания

- Публичный Project Hub пока содержит только начальную страницу и основные AI-документы.
- Полная документация из приватного репозитория ещё не опубликована.
- Автоматическая синхронизация между репозиториями ещё не настроена.
- Публичная база не должна содержать секреты и внутренние данные, не предназначенные для распространения.
- Исторические SQL-файлы нельзя считать актуальной схемой базы данных.
- Для изменений Supabase требуется проверка фактического состояния базы.
