## 7. Ограничения и важные замечания

- Публичный Project Hub содержит стартовую страницу, AI-документы и обзорные материалы по основным разделам проекта.
- Полная документация из приватного репозитория не опубликована.
- Автоматическая синхронизация между репозиториями ещё не настроена.
- Публичная база не должна содержать секреты и внутренние данные, не предназначенные для распространения.
- Исторические SQL-файлы нельзя считать актуальной схемой базы данных.
- Для изменений Supabase требуется проверка фактического состояния базы.
- Наличие описания функциональности в документации не подтверждает её реализацию в приложении.
- Актуальное техническое состояние приложения отдельно не подтверждено этим документом.
