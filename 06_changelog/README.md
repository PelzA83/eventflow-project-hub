
# EventFlow — Changelog

> История значимых изменений проекта и публичной документации.
> Последнее обновление: 11 ноября 2026 года.

## 1. Назначение

Журнал изменений фиксирует существенные события в развитии EventFlow.

Он помогает:
- отслеживать изменения проекта;
- понимать, когда появились новые решения;
- определять, какие документы обновлялись;
- передавать историю разработки между участниками и ИИ-платформами.

Журнал не заменяет Git history. Он содержит человекочитаемое описание важных изменений.

## 2. Правила ведения

В журнал добавляются:
- существенные изменения архитектуры;
- новые согласованные продуктовые решения;
- завершённые аудиты;
- значимые изменения базы данных;
- завершённые функциональные этапы;
- изменения структуры документации;
- изменения правил публикации публичных материалов.

Не нужно фиксировать каждую мелкую правку текста или форматирования.

Каждая запись должна содержать:
- дату;
- краткое название;
- описание изменения;
- затронутые разделы;
- статус, если он важен.
